# VibeSpark Technologies — Premium Enterprise Website Frontend

A modern, high-performance, enterprise-grade business website for **VibeSpark Technologies**, built following the official brand identity and approved design references.

---

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Node.js**: v18.0.0 or higher (v24.x tested and verified)
- **npm**: v9.0.0 or higher

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview the Production Build
```bash
npm run preview
```

## 🛠️ Technology Stack

- **Framework / Bundler**: React 19 with JSX + Vite
- **Styling**: Tailwind CSS v3.4 + PostCSS + Autoprefixer
- **Routing**: React Router DOM v7
- **Cinematic Animations**: GSAP v3 & GSAP ScrollTrigger
- **Micro-Interactions**: Framer Motion
- **Icons**: Lucide React + custom inline brand SVGs
